平台介绍

About the Platform

崇礼AI元医院智能化平台面向北京大学第三医院崇礼院区的专科服务与管理需求，下设四个业务子平台，分别为数字医生构建平台、患者服务与智能随访平台、医学科研辅助平台和数字医生治理与评价平台。四个平台通过版本审查与授权、服务评价与改进两项机制协同运行。医生遴选专科资料、设定服务范围，经院方审查、医生本人授权后，数字医生可用于就诊准备、健康宣教和康复随访。科研人员可整理多种形式的资料，形成可回查来源的结构化病例草稿。院领导和科主任可结合服务覆盖、专家抽检结果及随访完成情况，指导科室更新知识、改进服务，为专科经验向基层推广提供支撑。

两项协同机制

版本审查与授权

医生提交拟发布版本，伦理审查助手整理核对要点，院方审查并反馈意见。医生查阅报告、确认授权后，患者入口才切换到新版本。

服务评价与改进

院领导查看服务覆盖和质量趋势，科主任结合抽检与随访结果定位需要改进的环节。涉及回复或知识内容调整时，由医生修订并重新提交审查。

强基工程与专科应用

以崇礼运动损伤康复为例，科室可将复诊准备事项、随访问题和宣教资料整理成可复用的专科工具，供院内及基层协作场景使用。患者在随访中提出的个体康复问题交由医生判断。

崇礼AI元医院智能化平台面向北京大学第三医院崇礼院区的专科服务与管理需求，下设四个业务子平台，分别为数字医生构建平台、患者服务与智能随访平台、医学科研辅助平台和数字医生治理与评价平台。四个平台通过版本审查与授权、服务评价与改进两项机制协同运行。医生遴选专科资料、设定服务范围，经院方审查、医生本人授权后，数字医生可用于就诊准备、健康宣教和康复随访。科研人员可整理多种形式的资料，形成可回查来源的结构化病例草稿。院领导和科主任可结合服务覆盖、专家抽检结果及随访完成情况，指导科室更新知识、改进服务，为专科经验向基层推广提供支撑。
