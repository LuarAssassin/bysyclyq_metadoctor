# 崇礼 AI 元医院智能化平台 · 账号入口原型

用桌面或手机浏览器打开本目录的 `index.html`，点击「登录平台」并选择演示账号。系统按照账号打开相应工作区。演示支持患者和院内工作人员，页面、图像和三段教程视频均可离线使用。

| 演示账号 | 身份 | 进入后的主要任务 |
| --- | --- | --- |
| PT1001 | 患者 | 查看医生已授权的数字医生版本，了解就诊前需要准备的资料、健康科普及随访填写方法。 |
| CL1001 | 医生 | 管理自己的数字医生，处理随访反馈，维护知识库与科研资料，审查通过后确认授权。 |
| CL2001 | 科主任 | 查看本科室的服务量、随访质量和需求预测，了解科内数字医生的表现。 |
| CL3001 | 院领导 | 比较全院科室、服务趋势和需求预测，按科室查看数字医生的表现。 |
| CL4001 | 院方审核人员 | 核对版本、材料和服务范围，填写审查意见，通过或退回申请。 |
| CL5001 | 院方管理员 | 管理医生名册、入驻邀请与服务状态，查看运行记录。 |

从具体业务打开登录面板时，账号可访问该业务就直接进入；其余情况转到本人工作区并提示。刷新会保留当前标签页的演示账号。「切换账号」结束当前会话，可继续体验其他账号。在禁用脚本的预览中，同一入口可打开各账号的只读样例。

原型仅使用虚构账号和业务数据。演示操作记录保存在当前浏览器。审核人员通过版本后，还需医生本人确认启用，患者服务页才会展示新版本。实际应用需对接医院统一身份认证，并在服务端校验权限。

## 评审与测试

`index.html` 定义页面结构，样式文件控制桌面和移动布局。`scripts/navigation.js` 管理账号与访问范围，`scripts/model.js` 维护演示状态与操作限制。浏览器回归覆盖六类账号、桌面与手机布局、刷新和浏览历史、科室与全院的数据范围、版本审查与医生授权，以及禁用脚本时的只读入口。

在本目录下运行以下命令。已有本机 Chromium 时可通过 `CHROMIUM_PATH` 指定可执行文件，`npm test -- review` 可单独复查版本授权流程。

```sh
cd tests
npm install
npx playwright install chromium
npm test
```

## 生成离线文件

从原型根目录运行以下命令。门户打包需要 Python 3.9 或更高版本，独立大屏沿用上述回归测试的 Playwright 和 Chromium。门户包括所有账号的交互演示，大屏文件会直接进入院领导演示视图。

```sh
python3 tools/pack_portal.py . /tmp/Chongli-AI-Hospital.html
node tools/build-leadership.cjs /tmp/Chongli-AI-Hospital.html /tmp/Chongli-AI-Leadership.html
```

门户与管理大屏横向使用两枚院标，左侧为北京大学第三医院，右侧为崇礼院区。总院院徽及中英文字形来自[院方网站](https://www.puh3.net.cn/yywh.htm)。首页左侧为 AI 生成的崇礼冰雪主题背景，右侧轮播为院区、教学与科普实景，各张照片保留来源链接。
