# 崇礼 AI 元医院 · 身份入口原型

用桌面或手机浏览器打开本目录的 `index.html`，在首页选择身份即可体验。页面、图像和三段教程视频随目录提供，运行原型无需安装依赖。

| 身份 | 进入后的主要任务 |
| --- | --- |
| 医生 | 管理自己的数字医生、处理随访反馈、维护知识库与科研资料，审查通过后确认授权。 |
| 科主任 | 查看运动医学科的服务量、质量和需求预测，查看本科室数字医生的表现。 |
| 院领导 | 比较全院科室和服务趋势，可按科室查看数字医生的表现。 |
| 院方审核人员 | 核对版本、材料和服务范围，填写意见后通过或退回。 |
| 院方管理员 | 管理医生名册、入驻邀请与服务状态，查看运行记录。 |
| 患者 | 使用医生已授权的版本查看就诊准备事项、科普和随访演示。 |

所有任务、患者反馈、统计和预测均为演示数据。身份选择和操作记录保存在当前浏览器。审核人员通过版本后，还需医生本人确认启用，患者入口才会展示新版本。真实院方账号认证、服务端授权和业务数据接入需在生产开发阶段实现。

## 评审与测试

页面结构见 `index.html`，视觉样式在 `styles.css`。运行逻辑按功能放在 `scripts/` 中，`navigation.js` 定义身份入口和页面范围，`model.js` 维护演示状态与操作限制。图片和视频在 `assets/`，首页轮播提供原始影像的出处。

浏览器回归覆盖六个入口、桌面与手机布局、刷新和浏览历史、角色切换、科室和全院的数据范围、版本审核与医生授权，以及禁用 JavaScript 时的只读入口。安装 Node.js 后在此目录运行：

```sh
cd tests
npm install
npx playwright install chromium
npm test
```

已有本机 Chromium 时可用 `CHROMIUM_PATH` 指定可执行文件。用 `npm test -- review` 可单独复查版本授权流程。

门户和管理大屏使用上下排列的双标识。上方的北京大学第三医院院徽和中英文字标来自[院方网站](https://www.puh3.net.cn/yywh.htm)，下方沿用崇礼院区标识。门户背景为原创生成的崇礼四季山地意象插画，院区和医学教学轮播使用带来源的实景照片。
