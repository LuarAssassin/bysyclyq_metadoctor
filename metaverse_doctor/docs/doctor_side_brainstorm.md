# 北医三院崇礼院区元宇宙医生智能体

## 医生端功能头脑风暴（合并精简版）

### 菜单1：知识库与索引中心（原知识上传 + 状态展示合并）
定位：一个页面打通“上传文件、异步抽取、标签聚合、索引检索”，让医生低成本沉淀专业知识。
页面：左侧上传区，右侧状态列表、标签热力图、文件索引清单。
当前能力：已支持上传到 OSS、同步 Qwen 获取 `file_id`、抽取标签与描述、重试抽取、索引查询。
后续增强：手动编辑标签/描述、知识分组与版本、过期资料标记、低质量资料清理。

### 菜单2：数字人素材中心（原形象 + 声音合并）
定位：同一个入口管理医生“声音资产 + 视频资产”，减少操作切换。
页面：录音上传复刻音色、照片上传生成多场景视频、任务进度与可播放素材列表。
当前能力：已支持音色创建与激活、图生视频批量生成、状态刷新、私有桶签名地址回放。
后续增强：素材质检评分、自动筛选推荐素材、按演练场景打标签。

### 菜单3：医生叙事底座中心（原菜单3 + 菜单4 + 菜单6合并）
定位：统一管理医生的行医风格、表达方式、诊疗倾向、负向约束与红线规则。
页面：DSL 结构化编辑、批注驱动更新、红线规则管理、版本历史回看。
当前能力：已支持底座初始化与版本化更新、医生批注触发 Qwen-Max 抽取增量、红线增删、反例沉淀。
核心原则：底座学习以大模型抽取为主，不走规则兜底，保证更新有语义价值。

### 菜单5：AI 问诊演练场（重点）
定位：医生交付前的核心验收与持续优化入口。
页面：多轮对话、流式回答、知识出处、联网来源、token 消耗、Markdown 编辑、反馈学习。
当前能力：已支持会话管理、消息历史、RAG 检索两份关键知识、qwen-long 归纳、qwen-max 联网流式回答、播放资源下发、反馈回写底座。
后续增强：演练评分卡、病种模板化演练、批改对比视图、训练效果趋势。

## 一句话路线建议
医生端聚焦四个菜单就够用：知识沉淀、数字人素材、叙事底座、AI演练闭环；其他能力都围绕这四块做增强。
