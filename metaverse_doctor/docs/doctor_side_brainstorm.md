# 北医三院崇礼院区元宇宙医生智能体

## 医生端功能头脑风暴（合并精简版）

### 菜单1：知识库与索引中心（已完成基础）
定位：同一个页面完成“上传-抽取-检索-可视化”，降低医生操作成本。
页面：左侧上传文件，右侧实时展示抽取状态、标签列表、标签热力图和最近更新。
现状：已支持上传 OSS、Qwen 抽取标签描述、索引列表查询。
建议：补“手动编辑标签/描述、文件夹管理、知识版本、失效标记、未完成抽取过滤”。

### 菜单2：数字人素材中心（形象+声音）
定位：同一个页面管理数字人的视觉和声音素材，不让医生来回切菜单。
页面：照片上传、头像管理、语音样本上传、音色预览、照片转视频任务列表。
建议：统一做“素材质检 + 可用评分 + 风格标签”，只展示可用于生产的素材。

### 菜单3：人格底座提取与编辑
定位：把医生个人表达风格和价值偏好结构化。
页面：访谈问卷、历史对话导入、人格摘要自动生成。
建议：输出固定维度卡片：语气风格、解释深度、同理心强度、风险偏好。

### 菜单4：诊疗策略与话术模板（合并）
定位：把“怎么判断”和“怎么表达”放在一个地方统一配置。
页面：激进/平衡/保守滑杆、按病种策略模板、开场/解释/安抚/复诊话术模板。
建议：支持“按病种配置 + 医生个人版本 + 科室公共版本”。

### 菜单5：AI 问诊演练场（重点）
定位：让医生提前看到智能体在真实问答里的表现。
页面：模拟患者提问、实时回复、参考依据展示。
建议：增加“医生一键纠偏”，把修正内容回写到知识/人格训练池。

### 菜单6：负面提示词与红线规则
定位：把不能说、不能做、必须转人工的边界写成系统级规则。
页面：负面提示词库、禁答场景、越界触发词、风险等级。
建议：规则要可追踪、可版本化，并和模型提示词及回复拦截联动。

## 一句话路线建议
先把“知识库与索引中心 + 数字人素材中心 + 人格底座 + 策略话术 + AI演练 + 红线规则”六件事打穿，再扩展其他模块。
